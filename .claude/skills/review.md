## /review — 코드 리뷰 (체크리스트)

**언제:** 구현 완료 후, 클라이언트 납품·PR 머지 전

### Checklist (순서대로)

#### 1. **빌드 & 테스트**
- [ ] `npm run build` 성공?
- [ ] `npm run test` 성공? (또는 E2E 테스트)
- [ ] 개발 서버 실행 후 수동 테스트?

#### 2. **코드 정확성**
- [ ] 로직 버그 없음? (오프바이원, null 체크, 타입 안정성)
- [ ] 예외 처리 있음? (API 에러, 네트워크 끊김)
- [ ] 의존성 추가 승인받음? (새 라이브러리)

#### 3. **보안**
- [ ] `.env` 파일 노출 안 됨?
- [ ] SQL injection/XSS 취약점 없음?
- [ ] 인증 미들웨어 빠지지 않았나? (보호된 엔드포인트)

#### 4. **아키텍처**
- [ ] 계획(`/plan`)대로 구현됨?
- [ ] 파일 구조 일관성 있음?
- [ ] 재사용 가능한 로직 분리됨?

#### 5. **문서·메시지**
- [ ] 커밋 메시지 명확함? (`feat:`, `fix:` 접두사)
- [ ] 복잡한 부분 주석 있음?

---

**통과하면:** 클라이언트 납품 or 머지 → `/learn`에 발견 사항 기록
